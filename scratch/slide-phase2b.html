# Feature 01: Setup Conference Form
* Feature ID: F01 | Parent Flow: journey-01-setup-conference.md
* Bounded Context: conference | Status: 📋 Planned
## 1. Requisitos (Func. / No Func.)
Funcionales:
Crear evento (nombre, fechas, ciudad) y abrir CfP al publicar.
No Funcionales:
API < 200ms • auth organizer (JWT) • capas DDD estrictas.
## 2. Contrato de Errores HTTP
• 201 Created + Location: /cfp/[slug] (happy path)
• 409 SLUG_TAKEN: UNIQUE index → DuplicateSlugError (TOCTOU cubierto)
• 403 FREE_TIER_LIMIT_EXCEEDED: BR-004 (Application) → modal upgrade, cero rollback
• 400 VALIDATION_ERROR: Zod parse (Interface layer)
## 3. Ámbito por Capa (DDD)
Domain: Conference.create() + VOs (Slug, EventDates)
Application: CreateConferenceHandler + BR-004
Infra: Drizzle repo + Outbox
Interface: POST /api/v1/conferences + Zod
## 4. Checklist TDD (esta feature)
1º test de dominio (FAIL) ➔ 2º impl VO/entidad (PASS) ➔ 3º test handlers (mock) ➔ 4º check:arch 0 errores ➔ 5º lint + tsc
✂️
Regla de Oro Crafter: Una feature = un ciclo TDD completo. Si la IA salta de feature, el scope alucina y los tests dejan de ser el contrato.
