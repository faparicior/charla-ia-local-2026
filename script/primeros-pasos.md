# Idea inicial

NVIDIA Blackwell GB10 128Gb

- Software Ollama o similar
- Formato nativo proporcionado por NVIDIA. El famoso NVFP4
- Todo fácil… 

## Realidad

- Problemas de firmware de Asus 
- Errores de gestión de potencia de NVIDIA que obliga a desenchufar físicamente el ordenador y “contar hasta 10” 
- El formato NVFP4 está roto para este modelo de Nvidia Blackwell. Hay que reescribir las librerías para que puedan utilizarlo
- vLLM o Slang como alternativas para salir del paso
- Repositorios como Avarok y Eugr salen al rescate

## Noticias a buscar

- Foros de Nvidia hablando de la instrucción sm121 rota
- No podemos ejecutar NVFP4
- Buscar roadmap de (Fechas de resolución)
